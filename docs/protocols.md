# 内置协议模块

选择入口：`--protocol dk32s`、`--protocol datalink`；DK32S 一控多机遥控布局使用 `--protocol dk32s-multi`。

两个模块共用紧凑帧长度与 sum8 工具，但不共用方向判断和业务字段布局。既可使用 CLI，也可直接导入：

```python
from flrc_modem.parsing.protocols.dk32s import parse

application = parse(decoded_frame)
```

## 公共输出

`application` 包含 `protocol`、`direction`、`command`、`command_hex`、`command_name`、`sequence`、`need_ack`、`is_ack`、`payload_length`、`payload_hex`、`sum8_ok`、`wire_layout` 和 `fields`。

- 顶层 `payload_hex` 始终是完整物理载荷；`application.payload_hex` 是紧凑帧中的业务载荷。
- `direction` 是依据已知固件布局推断的 `ground_to_air / air_to_ground`，不是发射设备身份认证。DataLink 不能确定方向的命令返回 `unknown`。
- 外层长度、紧凑帧声明长度、sum8 或已知命令的字段长度不匹配，记录 `application_error`，不删除物理帧。
- 未知命令保留命令号、序号和 `fields.raw_hex`。未恢复含义的枚举仍输出数值，不编造产品名称。

## DK32S

代码：`src/flrc_modem/parsing/protocols/dk32s.py`。依据天空端 v0.1.5 的已恢复无线协议。

| 方向 | 封装 |
| --- | --- |
| 地面端→天空端 | 软件长度 1B + uint32/100μs 时间戳 4B + 紧凑帧 |
| 天空端→地面端 | 软件长度 1B + 紧凑帧 |

时间戳输出为 `timestamp_ticks` 和 `timestamp_sec`，与业务 `fields` 分离。

| 命令 | 已解析字段 |
| --- | --- |
| `11/16` 下行 | 16 路 11bit 通道原值、固件 +500 输出值、可选批次和透传数据 |
| `16/46` 上行 | 批次、透传数据；46 附加原始 16bit 电压值 |
| `12` | 失控保护模式、16 路掩码、通道原值与 +500 输出值；回复状态 |
| `13` | 配对过滤地址、20 项频道表，或过滤地址确认 |
| `17` | 有符号整数时间修正量及秒值 |
| `18` | 模式和同步计数 |
| `19/24` | 电压校准输入 mV，或回复状态 |
| `20/21` | 9 项 5bit PWM 映射；12B 块后 6B 作为未定义尾部原样保留 |
| `22/F0` | 32 位固件版本标识 |
| `23` | 20 项频道表 |
| `26/28,32/34,38,40,44/45,52/54,56,58/59` | 配置查询/设置值；40 同时映射波特率；空确认 |
| `30` | 操作号、端口1/2功能 |
| `36/50/53` | 通知值 |
| `5E/5F` | 扩展通道块、教练开关及通道值 |
| `60` | 多机配对阶段、设备编号、遥控器/接收机地址、过滤地址与频道表 |
| `62` | 3 个原始 uint32 参数；具体枚举含义未确认 |
| `64/66` | 探照灯开关、控制通道、亮度档位；空确认 |

`14/15/42/55/5D/F1` 等没有已确认业务字段的路径保留名称及原始字节。表中未定义的变体也不自动套用其他设备结构。

### 普通模式与一控多机

普通模式使用 `--protocol dk32s`；一控多机模式使用 `--protocol dk32s-multi`。后者在下行 `11/16` 的通道块前明确增加 `target_device_mask`、`device_number` 两字节。

不能根据载荷长度自动判断模式：普通模式的透传数据同样可以使长度超过 24B。`0x60` 配对消息本身在两个入口下均可解析。

## DataLink

代码：`src/flrc_modem/parsing/protocols/datalink.py`。软件长度后直接是紧凑帧，不使用 DK32S 的外层整数时间戳。

| 命令与属性 | 已解析字段/方向 |
| --- | --- |
| `F2, A=1/B=0` | 天空端→地面端：float32 浮点秒、批次、透传数据 |
| `F2, A=0/B=1` | 地面端→天空端：批次、透传数据，无前置时间戳 |
| `13, A=1/B=0` | 天空端→地面端：4B 过滤地址 + 20B 频道表 |
| `13, A=0/B=1` | 地面端→天空端：4B 过滤地址确认 |
| `17` | 4B 浮点传输延时秒值；按已确认请求/回复属性标注方向 |
| `F3/F5/F7, A=0/B=1` | 配置下发值；F7 映射波特率。此处 B=1 不表示天空端方向 |
| `18` | 2B 模式、同步计数，方向未确定 |
| `F0` | 4B 版本标识，方向未确定 |

配置确认包等未确认的业务布局保留原始字节。浮点 NaN/Inf 作为应用解析错误处理，避免生成非法 JSON。这里只解析无线协议，不解析串口/主机管理协议或透传内部的 MAVLink 等协议。
