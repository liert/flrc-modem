# SDR 实时频谱与瀑布图工作站

flrc-modem 提供了面向 USRP (UHD) 与 HackRF One 的仪器级 SDR 实时频谱与瀑布图工作站。系统在 WebUI 与后台服务中解耦硬件接收、数字信号处理（DSP）与前端图表渲染，具备有界缓冲流控、双边 FFT 幅度严格归一化、峰值保持、平滑平均与设备互斥生命周期管理。

---

## 1. 核心架构与数据流

实时频谱分析不同于全速基带 IQ 落盘或长时间离线分析，强调低时延、低主机负荷与高平稳性：

  └──────────────────┬──────────────────┘

                     ▼
  ┌─────────────────────────────────────┐
  │         DSP Worker (计算子线程)      │
  │   - 复数 IQ 转浮点基带 (cs8/sc16)   │
  │   - 加窗 (Hann/Hamming/Blackman...) │

  │   - 双边 FFT + fftshift             │

## 2. DSP 物理与数学保证

### 2.1 窗函数与 FFT 长度幅度归一化
为了确保在切换不同的 FFT 点数（512、1024、2048、4096）或窗函数（Hann, Hamming, Blackman, Rectangular）时，单音信号的幅值读数保持严格一致，系统采用**相干增益（Coherent Gain）**归一化：
$$S_1 = \sum_{n=0}^{N-1} w[n]$$
$$X_{\text{norm}}[k] = \frac{X[k]}{S_1}$$
$$\text{Power}_{\text{dBFS}}[k] = 20 \log_{10} \left( |X_{\text{norm}}[k]| + \epsilon \right)$$

对于满量程的正弦/复单音信号（$e^{j 2\pi f_0 t}$），无论选定何种窗函数或 FFT 长度，其主瓣峰值均稳定在 **0 dBFS**（误差不超过 $\pm 0.15 \text{ dB}$）。

### 2.2 功率单位严谨性
在未经标准射频信号源和步进衰减器进行硬件绝对功率标定之前，系统严禁显示未经校准的 `dBm`，统一显示定义清晰的相对功率 **`dBFS`**（Decibels Relative to Full Scale），避免仪器读数误导。

### 2.3 亚网格峰值抛物线插值
由于 FFT 存在频率栅栏效应，真实射频信号往往处于两个 FFT bin 之间。DSP 线程检测到局部最大点 $k$ 后，对其左右两点 $(k-1, k, k+1)$ 进行对数二次抛物线插值：
$$\delta = \frac{1}{2} \frac{P_{k-1} - P_{k+1}}{P_{k-1} - 2P_k + P_{k+1}}$$
$$\text{PeakFreq} = f_{\text{bin}}[k] + \delta \cdot \Delta f$$
$$\text{PeakPower} = P_k - \frac{1}{4} (P_{k-1} - P_{k+1}) \cdot \delta$$
该算法将中心频偏测量分辨率从 $\Delta f$ 提升至亚网格精度。

## 3. WebUI 界面与操作指南

### 3.1 导航入口
点击左侧主导航栏的 **「SDR 频谱」**（Radio 图标），进入专用实时频谱工作站。

### 3.2 参数设置区
- **设备配置**：
  - 复用全局设备选择器，支持 `USRP (UHD)` 与 `HackRF One`（以及调试用 `模拟仿真`）。
  - 设备定位参数（如 USRP 序列号/IP、HackRF 序列号/索引）由设备选择组件管理，表单内不重复冗余。
  - **USRP 专有参数**：子板通道选择（Channel 0 / 1）、天线端口（RX2 / TX/RX）、主时钟频率（例如 125 MHz、184.32 MHz）及偶数分频采样率联动匹配。
  - **HackRF 专有参数**：LNA 增益（0 ~ 40 dB，步进 8 dB）、VGA 增益（0 ~ 62 dB，步进 2 dB）、RF 放大器开关（0 / 14 dB）。
- **分析参数**：
  - **中心频率 (Center Freq)**：默认 2480 MHz，支持 1 MHz ~ 6 GHz 调谐。
  - **采样率 (Sample Rate)**：例如 2 MSps ~ 20 MSps。USRP 自动展示分频状态。
  - **FFT 点数**：512, 1024, 2048, 4096。
  - **窗函数**：Hann（推荐）、Hamming、Blackman、矩形窗 (Rectangular)。
  - **频谱平均 (Averaging)**：1（无平滑）~ 16 次指数滑动平均，降低白噪声起伏。
  - **刷新率限制**：5 ~ 60 FPS，防止浏览器高频重绘卡顿。
  - **显示范围**：Y 轴功率上下限（默认 -120 dBFS ~ 0 dBFS）。

### 3.3 运行控制
- **开始采集 (Start)**：请求独占锁，启动硬件流与后端 DSP，建立 WebSocket 推流。
- **停止采集 (Stop)**：安全释放硬件 RX 流，注销 WebSocket 监听，保留图表最后状态。
- **暂停显示 (Pause)**：冻结前端图表刷新，后端持续以有界环形缓冲接收；恢复时即时渲染最新数据。
- **清空瀑布图 (Clear Waterfall)**：重置画布历史。
- **峰值保持 (Peak Hold)**：保留频谱黄色包络线，支持一键重置。
- **动态调谐 (Dynamic Tune)**：采集运行中可直接调整中心频率或增益，后端通过线程安全队列下发调谐指令，无需重启采集进程；修改采样率或 FFT 点数等深层参数时，提示需重新启动采集以重构硬件网格。

### 3.4 交互读数与缩放
- **鼠标十字光标**：在频谱图上悬停即可显示精确到 kHz 的 RF 频率读数和 dBFS 功率。
- **峰值光标**：自动追踪当前视野内的全局最大峰值点。
- **频率缩放**：支持使用鼠标滚轮或下方滑动条进行频率区间框选放大，仅改变可视网格，**绝不隐式修改硬件射频前端调谐**。
- **瀑布图时间连续性**：瀑布图采用固定容量 Canvas 环形缓冲，纵轴反映真实采集时间戳。如果发生中心频率突变、采样率改变或硬件断流，瀑布图会绘制红/橙色隔离指示线，**绝不将不同频率网格混拼或伪装成连续信号**。

## 4. 生命周期与设备互斥安全

1. **设备互斥机制**：
   - 采集开始时调用 `DeviceManager.acquire_device(sdr, session_id)` 获得设备独占锁。
   - 若同一物理设备正在执行双工收发、测向同步或离线捕获，系统拒绝开启频谱并明确提示设备被占用。
2. **连接断开与泄漏防护**：
   - 前端 WebSocket 断开、浏览器页面关闭或切换标签页时，后端启动 15 秒心跳看门狗；若无客户端重连，自动停止采集并释放 SDR 硬件句柄。
   - 后端服务退出（FastAPI lifespan shutdown hook）时，调用 `SpectrumManager.shutdown()`，强制关闭所有活动会话。
3. **有界队列与背压保护**：
   - 硬件接收队列深度限制为 16 块；DSP 输出队列深度限制为 2 帧。
   - 若客户端渲染延迟或网络缓慢，后端直接丢弃陈旧帧并累加 `dsp_dropped_frames` 计数，避免内存无界膨胀。

### 6.2 硬件约束声明
- **无空口射频发射**：本功能仅配置 SDR 接收通道（RX），绝不启动发射机（TX），不会对外发射任何射频信号。
- **实机说明**：CI 及离线自动化测试基于模拟复单音及噪声基底运行；真实物理硬件需安装相应驱动（`libhackrf.dll` / `uhd.dll`）并在接入物理设备时按需运行。
