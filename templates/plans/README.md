# 同步收发编排模板

预设方案从本目录的 JSON 文件加载，界面中的名称、说明、报文、周期与步骤均来自文件：

- `heartbeat.json`：心跳保活轮询。
- `handshake_loop.json`：跳频协商与参数握手。
- `timing_ladder.json`：阶梯时延测试。
- `dk32s_relay_switch_probe.json`：接力控制、切换主副与固定频段未知同步字探测。

文件包含 `template` 元数据和 `plan` 编排定义。`template.schema_version` 为 `1`，`template.kind` 为 `duplex_plan`，`title`、`description` 用于菜单展示，`protocol` 标识所用报文协议。

`plan` 使用实际编排执行器的格式：`plan_id`、`periodic`、`steps`、`cycles`。任务可携带 `message` 或 `payload_hex`；两者只能选一项。周期任务设置 `interval_ms` 与 `count`，流程步骤设置 `delay_ms` 与 `on_failure`。至少需要一条任务，保存时复用执行器校验。

可以直接编辑文件，或在 WebUI 的“模板预设库 → 编排方案”中新建、编辑和删除。新建时先补充任务再保存，也可复制已有方案的内容修改。重新打开“预设方案”菜单会重新读取模板，无需重新编译前端。

选择方案只生成独立草稿，修改草稿不会自动覆盖模板；需在模板库中保存才能修改预设。已有的纯编排 JSON 导入/导出保持兼容，也支持直接导入带 `template` / `plan` 的模板文件。选择模板后仍需手动启动编排。

## DK32S 接力切换与同步字探测

在同步收发会话中选择 DK32S 物理层配置、原遥控器同步字（也可由原链路学习）和一个已知的监听频点，关闭“定时跳频”。无需获取接力遥控器的完整跳频表；会话保持固定频段接收，发送仍使用现有原链路的同步时隙调度。目标只有跳入监听带宽才会被捕获。

从“预设方案”选择“DK32S 接力切换与同步字探测”，然后开始编排。流程先确认原链路锁定并启动探测，再发送 `0x54 / rc_relay=1`；匹配 ACK 后发送 `0x55 / switch_vice=1`。第二步请求设备回复，但执行器不等待旧同步字 ACK，发送完成后继续观察 5 秒。任一步发送失败、第一步回复超时或手动停止均结束探测，不自动重试或切换发射同步字。

两条指令的发送极性、第一条指令的回复极性均沿用会话配置。如果天空端使用反码回复，请启用会话的“反转接收回复同步字极性”（CLI：`--reply-invert-sync`），并显式配置原同步字。

`plan.sync_probe` 是通用的编排伴随监听配置：

- `observe_ms`：所有发送任务结束后的额外观察时间，1..60000 ms，默认 5000。发送与等待回复期间也持续探测。
- `min_frames`：同一新同步字需要的独立有效地面帧数量，2..100，默认 3。
- `frequency_offsets_hz`：相对会话接收中心的目标频偏，1..9 项，默认 `[0]`。例如 `[-500000, 0, 500000]` 在同一份 IQ 中解调三个目标频点；目标及其滤波通带必须在实际采样带内，否则启动前拒绝整个编排。可在模板库修改此项。相邻解调频点捕获的同一物理帧不会重复计数。这是指定频点监听，不是整个采样带内任意载频的连续盲扫。

探测仅接受通过物理层 CRC 和 DK32S 校验和的地面帧，排除原同步字、反码、自身发送回波和同步字/CRC 初值存在歧义的帧。独立有界队列满时丢弃旧窗口，不阻塞主收发解码；界面记录探测丢窗、接收溢出和断流。候选不会进入原链路时钟、回复匹配或自动接管发射。

结果在“发送编排”中显示并持久保存：`candidate_found` 仅表示候选达到帧数门槛，不等于已确认属于接力遥控器；`insufficient_frames` 表示帧数不足；`not_observed` 表示监听范围内未捕获，不能据此判定切换失败。采集缺口单独标记。中断后不会自动恢复发送。

CLI 使用同一执行器，通过 `flrc duplex --session --config templates/physical/dk32s.toml --frequency <监听频率Hz> --sync <原同步字>` 建立会话，在 stdin 发送单行 `{"action":"start_plan","plan":...}`（`plan` 取模板中的同名对象）。探测状态和结果通过 `duplex.probe` JSONL 事件输出。携带探测的编排不允许无限周期任务，以便按时进入最终观察阶段。

也可以直接执行模板，结束后自动退出：

```powershell
flrc duplex --config templates/physical/dk32s.toml --frequency 2471660000 --sync <原同步字> --plan-file templates/plans/dk32s_relay_switch_probe.json
```

请将示例频率与原同步字替换为当前链路的实际值；USRP 地址使用现有 `--args` 参数配置。指令执行失败时该单次入口返回非零退出码；未捕获候选仍输出观察结果，不将其等同于指令失败。
