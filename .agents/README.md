# 项目技能

技能保存在本项目的 `.agents/skills/`，无需安装到用户全局目录。

| 技能目录 | 用途 | 来源 |
| --- | --- | --- |
| `web-design-guidelines` | 可访问性、键盘操作、反馈、响应式布局检查 | [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) |
| `react-best-practices` | React 状态订阅、渲染性能和异步操作规范 | [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) |
| `logging-best-practices` | 结构化日志规范、分级标准与日志治理 | [boristane/agent-skills](https://skills.sh/boristane/agent-skills/logging-best-practices) |
| `observability-and-instrumentation` | 系统指标监控、健康状态诊断与可观测性规范 | [addyosmani/agent-skills](https://skills.sh/addyosmani/agent-skills/observability-and-instrumentation) |
| `async-python-patterns` | Python 异步并发、事件循环与流控背压规范 | [wshobson/agents](https://skills.sh/wshobson/agents/async-python-patterns) |

开发时按任务选用对应规则，并继续遵守项目已有的硬件安全约束及深色视觉规范。界面验证优先使用代码检查、前端测试与构建，按用户需要再做浏览器检查。
